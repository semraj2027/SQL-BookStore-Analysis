# 📚 Book Store SQL Analysis

A complete SQL project that analyzes bookstore sales, customers, and inventory using MySQL.

---

# 📌 Project Overview

This project demonstrates how SQL can be used to analyze a bookstore database.

The project consists of three related tables:

- Books
- Customers
- Orders

Relationships were established using Primary Keys and Foreign Keys to maintain data integrity.

---

# 🎯 Objectives

- Analyze bookstore sales
- Track customer purchases
- Calculate revenue
- Monitor inventory
- Practice SQL joins and aggregation

---

# 📂 Dataset

The project contains three datasets:

- Books.csv
